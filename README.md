# Jungle Cook

Responsive Home and Login pages built with Vite, JavaScript, SCSS, and Firebase Authentication.

## Features

- **Authentication**: Login and Sign Up forms use Firebase Authentication.
- **Future Enhancements**: Firestore and Storage will be used for recipe pages in later assignments. Current Firestore access is restricted.

## Getting Started

### Prerequisites

- Install [Node.js](https://nodejs.org/).
- Create a Firebase project in the [Firebase Console](https://console.firebase.google.com/).

### Firebase Configuration

1. Create a Firebase project and add a Web app in the Firebase Console.
2. Enable **Email/Password** authentication under Authentication > Sign-in method.

## Version Control with GitHub

1. Create a new repository on GitHub.
2. Run the following commands, replacing `YOUR_GITHUB_REPOSITORY_URL` with your repository URL:

```sh
git init
git add .
git commit -m "Build Jungle Cook home and login pages"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```
